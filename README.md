# Urban Property Price Trend Forecasting

## Project Overview

This project develops a machine learning system for forecasting
urban property prices using property characteristics and
infrastructure development signals.

The system predicts the expected property price after 12 months
and identifies the expected price trend.

## Objectives

- Predict future urban property prices.
- Analyze the effect of infrastructure development.
- Forecast 12-month property price trends.
- Provide an interactive prediction dashboard.

## Input Features

- Property area
- Number of bedrooms
- Distance from metro
- Distance from highway
- Distance from school
- Distance from hospital
- Road development
- Metro development
- Commercial development
- Current property price

## Machine Learning Algorithm

Random Forest Regression

## Output

- Current property price
- Forecast property price
- Expected price growth
- Price trend
- Infrastructure impact
